# 路线裁决：换模型 / 1Cat-vLLM / 留守（三子代理辩论终稿）

> 2026-10-12。参与：事实侦察（VLLM-ROUTE-facts.md）、性能建模（VLLM-ROUTE-perfmodel.md）、红队（VLLM-ROUTE-redteam.md）+ 主线实测（v39 分解、1Cat 仓库取证）。服务器闪断期间基于本地完整镜像取证，恢复后待补 `/home/debian/ac922-vllm` 实地核对。

## 一句话裁决

**留守 monster 树 + P3 内核/接受率正攻线（三臂一致，红队置信 75%）。换 1Cat-vLLM 跑 Flash-Next 是已两次弃线的死案；换模型单独不达标，只作留守线的二期放大器。**

## 各路线判决

### ❌ B1：1Cat-vLLM + Flash-Next（含 RadixArk NVFP4 + PLE 磁盘化）

- **9 月实测**：GGUF 路线 ppc64le 上最好 29.2 tok/s（vs monster 134-140）；512-token parity 至今未过；MTP 头（block-48）从未加载成功；加载 537-550s。
- **10 月两次弃线**（红队取证）：Codex 线第 6 token 分岔未解；ZCode 线 TP3×PP2 两次死于 `stopped_first_token_mismatch` / `graph_replay_unverified`（decode 19.8、MTP 接受率 0%）。
- **硬件墙**：qwen4exp 层 TP4 需 24GB/rank 双银行（16GB 物理装不下）；PLE 728× I/O 放大；ppc64le 轮子栈在 RAM 盘，重启蒸发。
- RadixArk NVFP4（126GiB，PLE 47.7GiB 磁盘化后 GPU 侧 ~78GiB 名义可装）**绕不开上述任何一堵墙**；x86 参考成绩（C1 92.3 / C4 280）是 4×32GB+x86 契约，ppc64le 不可复现。

### ⚠️ B2：复活 27B 稠密 @ 1Cat 生产配置（备选，产品决策）

- 唯一接近目标的**已验证**配置：4×1k all-live 367（峰值）/ 30 分钟持续 ~180 聚合；曾上生产 8000 口。
- 1-2 天可复活验证（轮子底座在）。但换掉 Flash-Next = 模型质量换吞吐，**用户拍板项**，非工程默认。

### ⚠️ C：换模型（monster 树内）

- 单独换：字节减半只到 ~40/流（<50 目标）；小 MoE +15-60%（135-210）。收益全来自 dense 部分缩小，专家池同构不变——治标。
- **作为 A 线二期放大器**：Next-80B@Q4（保 GDN/MTP 语义）→ 330-530 聚合。一期达标后再议。

### ✅ A：留守 monster + 内核/接受率正攻（主线）

建模臂字节账：**单 token 仅读 5.28GB（dense 占 83%），4 路带宽天花板 2293 tok/s——实测 93-100 = 内核效率 4.1-4.4%**（dense 15%、专家链 4.7%）。空间在内核，不在模型，不在拓扑（TP6/岛平衡/结构图全持平已实证）。

达标组合拳（每级独立可验证）：
1. **P3 内核**：专家链效率 4.7%→10/20%（IQ LUT 重打包、TurboMind 式 grouped GEMV、dequant+GEMM 融合）→ 聚合 162-234
2. **接受率修复**：多路 a≈1.6-2.3 → 单流级 ~3.0（放宽 speculative.cpp `n_seq==1` 门，fold/gpu_carry 快链多路化）→ 306
3. **4 路合批调度**（SPEC_PAD_MULTI/固定形状）→ 433

目标 ≥200 在第 1+2 级射程内；4-6 周量级；正确性门/测量协议/全部基建复用。

## 两周决定性信号（按序）

1. v31 PATH_LOG（eager/replay 审计，用户 CUDA graph 假说终审）
2. 多路接受率差距定位（`n_seq==1` 门放宽的最小改码实验）
3. d2 + LLAMA_SPEC_PAD_MULTI=12 联测
4. 27B@1Cat 复活验证波（可选，为 B2 备胎定价）
5. P3 第一个内核（dense 15%→25% 单件）——若 4-6 周预算不可接受，回头看 B2

## 用户假说对账

| 假说 | 判决 |
|---|---|
| "MTP 接受率是瓶颈" | **否**（v39 实测 0.72-0.81），但多路接受率仍低于单流、修复有增益 |
| "避跨岛是元凶" | **否**（E1 TP6 持平+跨岛 AR 免费），副产品=拓扑自由度 |
| "换 1Cat-vLLM 更好" | **否**（Flash-Next 死案；27B 是换模型不是换引擎） |
| "PLE 磁盘化可救装载" | 对（装载可行），**但救不了 16GB 双银行墙/MTP 头/728× I/O** |
| "换模型更好" | 单独**否**；作二期放大器**是** |
| （v39 实证）真瓶颈 | **小批量细粒度 MoE/GEMV 内核效率 4-5%** |
